# Documentation NathAnimAge

La documentation est separee selon le niveau de maturite du produit.

## POC UX/UI

Le dossier [poc](poc/README.md) decrit une version volontairement simplifiee et sans module externe. Elle permet de valider :

- la comprehension des ecrans ;
- l'ordre des actions ;
- les libelles et appels a l'action ;
- le confort d'utilisation sur ordinateur et mobile ;
- la difference entre l'espace animatrice et l'espace famille.

## Application complete

Le dossier [application-complete](application-complete/README.md) decrit la cible professionnelle : frontend, backend, donnees, authentification, services d'IA, stockage, securite et deploiement.

Cette documentation ne doit etre utilisee pour lancer la realisation qu'apres validation du POC.
